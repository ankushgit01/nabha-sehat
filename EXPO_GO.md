# Run on your phone with Expo Go

1. `npm install`
2. `npx expo start -c`
3. Scan the QR code. On iPhone, use the Camera app; on Android, use the Expo Go app.

Voice input (speech-to-text) is not available in Expo Go, so the mic button is disabled with a note. Everything else works: symptom check, triage, SOS, first aid, records, hospitals and the Ayushman check.
